Fillable and non-fillable forms

When you open a form, the editor looks for real form fields — text boxes, check boxes, radio buttons, dropdown lists and list boxes — and highlights them in blue. Click one and type or choose, just like on a web form. Fields that appear more than once in a document stay in sync automatically.

Some PDFs (especially scanned ones, or forms exported from Word) have no real fields. For those, use the Text tool to type on the page, the ✓ Check tool to tick boxes, and Date for today's date.

How to fill a PDF form

  1. Open the editor and choose your PDF.
  2. Click the blue fields and fill them in. Use Text, ✓ Check and Sign for anything that isn't a field.
  3. Press Download PDF. Your filled-in copy is created on your device — nothing is uploaded.

Your personal details stay private

Forms usually contain names, addresses and ID numbers, so privacy matters more than convenience. This editor runs entirely in your browser; the form is never sent to a server. The editor page has no ads or trackers at all, and its security policy stops it from contacting any other website.

Things to know. Fields marked read-only by the form's author can't be edited. Some government forms rely on special scripts (for example automatic date formatting or calculations) that run only in desktop PDF software — this editor fills in the values but doesn't run those scripts. Password-protected forms are not supported yet. Always check the downloaded copy before you submit it.

Questions

Will the filled form still look like the original?

Yes. The original page is kept exactly as it was; your entries are written into the form fields (or drawn on top for non-fillable forms).

Can the next person still edit my answers?

Yes — answers are saved into the form's own fields, so they remain editable in other PDF software unless you print or flatten the file.

Can I use Sinhala or Tamil in a form field?

PDF form fields can't hold those scripts reliably, so the editor draws that text onto the page at the field's position instead, as a sharp image. It looks right, but it is no longer a typed form value.

Is there a size or page limit?

No page limit. Files up to 300 MB are accepted; very large ones simply depend on your device's memory.
