A note on "ASCII"

True ASCII only covers codes 0-127 (basic English letters, digits, punctuation). This tool uses full Unicode code points, so it also correctly handles accented letters, non-Latin scripts, and emoji — a strict ASCII-only tool would break on anything outside the original 128-character set.
