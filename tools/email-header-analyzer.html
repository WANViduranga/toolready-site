Email Header Analyzer

Paste the full raw headers from an email (in Gmail: "Show original"; in Outlook: "View message source") to see the delivery path and authentication results.

Summary

Authentication results (SPF / DKIM / DMARC)

Delivery path (oldest hop first)

Each "Received" header is added by a mail server as the message passes through it. Parsing real-world header formats is genuinely messy — the extracted "from"/"by"/"time" fields below are best-effort; the full raw line is always shown too so you can verify.

What to look for

A phishing red flag: the "From" address domain doesn't match the domain in the earliest (originating) hop, or SPF/DKIM/DMARC all show "fail" or "none" for a message claiming to be from a well-known company. Large, unexplained time gaps between hops can also indicate a message was held or relayed through an unexpected system.
